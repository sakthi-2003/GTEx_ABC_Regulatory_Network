# Results Directory

This directory stores analysis outputs that are small enough to track in the repository.

- `networks/`: network edge lists and Cytoscape-ready tables
- `enrichment/`: functional enrichment result tables
- `tables/`: hub gene summaries, regulatory class overlaps, and curated result tables

Current tracked outputs include:

- `enrichment/gprofiler_key_findings.tsv`
- `tables/top_hub_genes.csv`
- `tables/regulatory_overlap_summary.csv`

The large Cytoscape topology export can be added with a standard Git push or GitHub web upload.
