# Network Edge Lists and Topology Files

This directory stores network-oriented data products used for Cytoscape and downstream topology analysis.

- `cytoscape_networks_genes.csv`: Cytoscape-exported network node topology metrics, including degree, betweenness centrality, closeness centrality, clustering coefficient, stress, and related graph statistics.

Full co-expression edge lists generated by the workflow can be placed here when preparing a reproducible public release.
