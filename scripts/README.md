# Scripts Directory

The active analysis workflow is consolidated into three professional scripts:

- `01_build_gtex_coexpression_network.R`: GTEx expression filtering, highly variable gene selection, Pearson correlation, and co-expression edge construction.
- `02_integrate_abc_and_export_network.R`: gene symbol mapping, ABC enhancer-gene filtering, GTEx-ABC integration, and Cytoscape export.
- `03_analyze_hubs_enrichment_and_plots.R`: hub gene summarization, regulatory-class interpretation, enrichment summaries, and hub gene plotting.

This compact structure is designed to be easier for reviewers, graduate admissions committees, and computational biology portfolio readers to follow.
